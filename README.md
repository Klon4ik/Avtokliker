# Автоклікер / Auto Clicker

[Українська](README.md) · [English](README.en.md)

Автоклікер для **Windows 10/11** з українським та англійським інтерфейсом. Підтримує кілька точок із різними інтервалами, перетягувані кружки на екрані та автоматичні клавіші й комбінації Ctrl/Alt/Shift.

## Завантаження та запуск

1. **[Завантажте готовий ZIP для Windows](https://github.com/Klon4ik/Avtokliker/raw/refs/heads/main/downloads/Avtokliker-Windows.zip)**.
2. Розпакуйте **всю папку** у зручне місце, де дозволено зберігати файли, наприклад у «Документи».
3. Запустіть **Start.cmd** або **app/AvtoClicker.exe**. Не запускайте програму зсередини ZIP.
4. Для ярлика на робочому столі запустіть **Create-Shortcut.cmd**. З'явиться ярлик **Auto Clicker**.

Програма використовує **.NET Framework 4.x**. Python, .NET SDK, інтернет для роботи та інсталяція пакетів не потрібні. Готовий виконуваний файл також є в папці [app](app). Якщо ви завантажили весь репозиторій через **Code → Download ZIP**, використовуйте ті самі кроки після розпакування.

## Мова / Language

Виберіть **Українська / Ukrainian** або **English** у списку в правому верхньому куті вікна. Інтерфейс змінюється одразу, без перезапуску. Назви ваших дій залишаються такими, як ви їх написали. Вибір мови зберігається у профілі та відновлюється під час наступного запуску. Під час автоматизації спочатку натисніть **F9**, щоб змінити мову.

## Як налаштувати

1. Натисніть **+ Точка кліку**. Оберіть ліву, праву або середню кнопку миші.
2. Натисніть **Вибрати на екрані · 3 с** та за три секунди наведіть курсор на потрібне місце. Вікна тимчасово сховаються, після чого координати збережуться. Також можна ввести X/Y вручну.
3. Вкажіть інтервал у секундах, затримку першої дії та кількість повторень. **0 повторень** означає без обмежень. Мінімальний інтервал — **0,01 с**.
4. Додайте інші точки. Для кожної можна встановити інший інтервал.
5. Натисніть **+ Клавіша**, оберіть клавішу та за потреби Ctrl, Alt, Shift. Клавіші надсилаються в активне вікно; кліки можуть змінювати це вікно.
6. Залиште відлік **3 с** та опцію згортання, натисніть **Запустити** й перейдіть у цільову програму.

## Кружки на екрані

Увімкніть **Показати точки на екрані**: кожна точка миші з'явиться поверх інших вікон як кольоровий кружок із номером. Номер відповідає **№** у таблиці. Точне місце кліку — **перехрестя в центрі** кружка.

- **Перетягуйте кружок лівою кнопкою миші**, щоб перемістити точку. Координати в таблиці оновлюються одразу та зберігаються після відпускання кнопки.
- **Розставити точки** вмикає кружки й згортає головне вікно. Кружки залишаються видимими поверх потрібної програми.
- Щоб додати кілька кружків, використовуйте **+ Точка кліку** або **Копія**. Для кожної точки зберігається її власний інтервал.
- **Подвійний клік по кружку** відкриває налаштування відповідної точки.
- Після **F8** кружки пропускають кліки до вікон під ними й коротко підсвічуються під час виконання дій. Під час виконання та відліку їх не можна пересувати. Натисніть **F9**, щоб зупинити й знову редагувати точки.
- Вимкнені в таблиці точки мають сірі пунктирні кружки. Прапорець показу зберігається у профілі. Зніміть його, щоб прибрати всі кружки.

Кружки тимчасово ховаються під час відкриття діалогів налаштування та вибору файлів і закриваються разом із програмою. Якщо точка опинилася поза підключеними екранами, її кружок не відображається; задайте доступні координати через **Змінити** або **F6**.

Кожна дія має окремий розклад. Перший запуск дії відбувається після загального відліку та її початкової затримки; наступні — через її інтервал. Дії працюють паралельно за розкладом, але переміщення курсора й кліки Windows отримує послідовно: системний курсор один. Пропущені під час сну комп'ютера інтервали не виконуються накопиченою серією. Точність залежить від навантаження Windows, особливо для інтервалів 10–20 мс.

## Гарячі клавіші

| Клавіша | Дія |
| --- | --- |
| **F6** | Зберегти поточні координати курсора у вибрану в таблиці точку. Працює, коли автоматизацію зупинено, навіть якщо активне інше вікно. |
| **F8** | Запустити або зупинити всі увімкнені дії. Повторний запуск починає відлік і лічильники спочатку. |
| **F9** | Негайно зупинити автоматизацію або скасувати відлік. |

F6, F8 і F9 зарезервовані для керування й не доступні як автоматичні натискання. Якщо вони зайняті іншою програмою, автоклікер повідомить про це й заблокує запуск до перезапуску з вільними клавішами. Закриття програми зупиняє всі дії. Під час фізичного утримання кнопки миші чи Ctrl/Alt/Shift/Win автоматичні дії пропускаються без збільшення лічильника; вони продовжаться після відпускання.

## Профілі та ярлик

- Усі зміни автоматично зберігаються в **app/settings.json** поруч із програмою. Попередня версія — **app/settings.json.bak**.
- Кнопки **Зберегти профіль** і **Відкрити профіль** дозволяють мати кілька наборів налаштувань у JSON-файлах.
- **Create-Shortcut.cmd** створює ярлик **Auto Clicker** на робочому столі. Після переміщення папки програми запустіть його повторно, щоб оновити шлях ярлика. Локальна збірка через **build.ps1** також створює ярлик **Автоклікер.lnk** у папці проєкту.
- Координати підтримують кілька моніторів, зокрема від'ємні X/Y. Після зміни розташування моніторів або масштабу перевірте точки повторно.
- Якщо цільова програма запущена від адміністратора, для взаємодії з нею автоклікеру можуть знадобитися такі самі права. Деякі програми та ігри не приймають синтетичне введення.

## Збірка та перевірка

Вихідний код — **src/**, збірка використовує вбудований у Windows компілятор .NET Framework, без завантаження залежностей:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Test
```

Перед збіркою закрийте запущену програму, щоб Windows дозволила замінити EXE. **14 автоматичних перевірок** охоплюють незалежні інтервали, затримки й повторення, зупинку, помилки введення, профілі та резервне копіювання, структури SendInput, координати кількох моніторів, перетягування кружків і перемикання мов зі збереженням дій. Самоперевірка не надсилає реальних кліків або клавіш.

Щоб зібрати готовий ZIP із перевіреної програми та інструкцій:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Package.ps1
```

Результат: **downloads/Avtokliker-Windows.zip**. До пакета потрапляють лише програма, її значок, інструкції та скрипти запуску/ярлика. Особисті профілі, резервні копії та ярлики з локальними шляхами до репозиторію й пакета не додаються.

Окремий профіль можна відкрити одразу під час запуску: `app\AvtoClicker.exe --profile "C:\шлях\профіль.json"`. Зміни автоматично зберігатимуться у вказаний файл.

Введення реалізоване через Windows [SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput), координати — через [MOUSEINPUT](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-mouseinput).
